## Important technical distinctions

- Neo4j: default read committed, possible nonrepeatable reads/write contention; conventional clustered database has one elected write coordinator, not one active client transaction. Edition and specialized sharding distinctions matter.
- PostgreSQL/AGE: MVCC and selectable transaction isolation; pin a released/tested PostgreSQL/AGE/pgvector combination. AGE FAQ/repository version guidance differs. Do not assume full Neo4j feature compatibility or arbitrary managed-host extension availability.
- ArangoDB: distinguish single-server/OneShard guarantees from distributed multi-server transaction failures. Current Community binary commercial-production restrictions and 100 GiB cap differ from BUSL source terms. Vector indexes are trained and may need rebuilding as distributions change.
- GraphDB 11.5: parallel readers with sequential update processing and read committed; configurable inference, separate search projection.
- Jena TDB2: serializable MVCC, multiple readers, one active writer. Use Fuseki/shared server access; do not open the same storage directory from independent processes. Reasoning requires deliberate configuration.
- Neptune Database: one primary write coordinator, read replicas, ordinary read-only snapshot behavior and session-specific exceptions. Neptune Analytics is separate; its vector changes are non-atomic/non-isolated. Do not transfer Database ACID claims to Analytics vectors.

Each distinction has official source links in the research/comparison documents. No database has been selected, installed, deployed or benchmarked. No empirical winner or demonstrated request capacity exists.
