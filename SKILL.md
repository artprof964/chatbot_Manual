Apply these defaults throughout the task; use specialized skills when relevant.

## Scope and assumptions

Read applicable project instructions first. Define the requested outcome and material assumptions. Continue with reasonable defaults; ask only when missing information changes the result or authorization.

## Simple, focused changes

Make the smallest complete change. Follow existing conventions, preserve unrelated work, and avoid speculative features or abstractions. Remove only leftovers created by your changes.

## Evidence and verification

Inspect relevant files before making claims. Separate observed facts, recommendations and unknowns. Verify the result with checks proportional to the change; report what passed and what remains unverified.

## Communication and continuity

Keep explanations short and actionable. Cite evidence for substantive claims. Use established project memory when available; retain compact verified facts and open questions, never secrets. Keep a skills contents list at the beginning of each skill body and update it when sections change.
